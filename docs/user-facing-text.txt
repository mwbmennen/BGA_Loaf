NOTES
================================================================================
- No states.inc.php / descriptionmyturn strings exist yet in this repo --
  the BGA state-machine description text (shown in the status bar by the
  framework itself, independent of the custom setTitle() calls above) has
  not been authored. Section 4's setTitle() calls currently substitute for
  that.
- Section 2's fragments are never shown to players standalone; they're
  always substituted into a Section 1 or Section 3 template string.
- The Core/*.php `InvalidArgumentException`s (ScoringCalculator,
  RoundResolver, TargetGroupResolver, SwapEffectResolver,
  ReviewEffectResolver) are deliberately NOT catalogued here -- they're
  pure-logic precondition violations in DB-free Core classes, not meant to
  ever reach a real player under correct UI gating. Where one legitimately
  can (SwapEffectResolver's invalid-choice case), ResolveAdvancedEffect.php
  already catches it and re-throws as a translated UserException (see
  section 9) at the BGA-adapter boundary -- that's the pattern to follow
  for any new Core exception that might someday surface to a player.
